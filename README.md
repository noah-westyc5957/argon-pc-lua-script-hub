## Frequently Asked Questions

**Does Argon PC support operating systems other than Windows?**  
No. The current release is intended for 64-bit Windows 10 and Windows 11 desktops.

**Can an older release remain compatible after a Roblox update?**  
Roblox changes may affect compatibility with previous builds. Newer releases with auto-update support are the recommended way to remain aligned with the current version.

**What is Argon PC's focus compared with other script executors?**  
The application prioritizes a compact interface, access to a 500+ script hub, batch processing, and integrated debugging instead of a large or complex desktop layout.

**Can using a script executor create account-related risk?**  
Third-party tools should always be used with consideration for the platform's terms and the user's own responsibility. Check the latest policies before using one.

**Are any files or workflow details saved locally?**  
Yes. Persistent queue storage is included, so certain workflow data can remain on the local device.
